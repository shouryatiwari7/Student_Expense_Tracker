# Problem Statement

## Problem

Students often manage their own money for the first time and usually do not track small daily spending such as food, travel and stationery. Without a record, they cannot see where their money goes and often overspend before the month ends.

## Scope

The project is a command-line application that lets a single user record and manage personal expenses, analyse them, and monitor a monthly budget. Data is stored locally in a text file. It does not include a graphical interface, online accounts, bank connections or multi-user support.

## Target Users

- College and hostel students managing a monthly allowance
- Anyone who wants a simple, offline way to track daily spending

## High-Level Features

1. Expense management: add, view, update and delete expenses
2. Analysis: total spent, biggest expense, spending per category, kth largest expense
3. Budget alerts: set a monthly limit and receive warnings and alerts
4. Data validation on every input
5. Persistent storage in a local text file
